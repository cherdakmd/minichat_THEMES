## [Unreleased]

## [1.2.0] — 2026-11-25

### Added
- 4 новые темы: **CRT ТВ** (телетекст, развёртка, помехи при донате, OSD),
  **Табло Split-flap** (механические «лепестки», заголовок табло),
  **Космическая миссия** (звёзды, метеоры, туманность, HUD с миссионным таймером),
  **Cyberpunk** (глитч-заголовок, срезанные углы, сканлайн-полоса);
- библиотека эффектов **ThemeFX** во всех темах: глитч донатов (RGB-split),
  конфетти на canvas, звук донатов/событий (WebAudio-синтез, без файлов),
  автоцвет ника по хешу имени, снегопад на фоне;
- свойства эффектов во всех темах: `GlitchDonations`, `ShowConfetti`,
  `EnableSound`, `SoundVolume`, `AutoNameColor`, `EnableSnow`, `SnowAmount`;
- GitHub Actions: автопроверка манифестов (CI) и автосборка релизов
  с настоящими ZIP-ассетами;
- секция «Скачивание» и витрина 12 тем в README.

## [1.1.0] — 2026-11-25

### Added
- 15+ настроек в каждой теме: скругление краёв, тень текста (5 видов + цвет),
  подложка с прозрачностью, акцентный цвет, время сообщений, отступы,
  насыщенность шрифта, межбуквенный интервал, длительность анимаций,
  размер и форма аватаров, максимальная ширина;
- тумблер «Наклон пузырей» в Комиксе;
- Live-события и починенные значки в Dos.

### Fixed
- заглушка превью: свойства манифеста применяются реактивно (через `$data`),
  демо-сообщения несут поле `Time`.

## [1.0.0] — 2026-11-25

### Added
- первые 7 тем: Матрица, Аркада, Windows 95, Неон, Вейпорвейв, Комикс, Minecraft;
- оригинальная тема DOS как эталон формата;
- живое превью-галерея с имитацией чата (`python3 preview/serve.py`);
- документация формата темы (`docs/THEME_FORMAT.md`), баннер, MIT-лицензия.
